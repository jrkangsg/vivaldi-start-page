캘린더 표시 설정

공개 캘린더는 API 키로, 비공개 일정은 Google 로그인으로 읽습니다.

Google Cloud에서 Calendar API를 활성화하고 키 또는 웹용 OAuth 클라이언트 ID를 생성하세요. 클라이언트 보안 비밀은 입력하지 않습니다.
